# Update Template

Use this template for every completed ticket/process update file in [updates](../updates).

Filename format:
`YYYY-MM-DD_HH-MM-SS_ticket-id_short-title.md`

## Template

```md
# Update: <Short Title>

- Timestamp: <YYYY-MM-DD HH:MM:SS>
- Ticket: <TICKET-ID>
- Status: Completed

## Summary
<1-3 bullets of what was completed>

## Changes Made
- <change 1>
- <change 2>

## Files Changed
- [path/to/file1](../path/to/file1)
- [path/to/file2](../path/to/file2)

## Validation Evidence
- <command/check 1 and result>
- <command/check 2 and result>

## Open Risks or Follow-ups
- <risk/follow-up 1>
- <risk/follow-up 2>

## Next Ticket
- <NEXT-TICKET-ID - Title>
```
