# FOLIO Report Explorer

A full-stack application for exploring the FOLIO LDP database schema, building
queries visually, and generating SQL with AI.

## Stack

- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS
- **Backend:** Yii2 PHP 7.2 REST API
- **AI:** Gemini 2.5 Flash for natural language → SQL
- **Database:** Remote PostgreSQL (FOLIO LDP), local MySQL (app state)
- **Infra:** Docker Compose (nginx, php-fpm, mysql, node)

## Quick Start

```bash
cp .env.example .env
# Edit .env with your Postgres credentials and Gemini API key
docker-compose up -d
```

Open http://localhost:8080

## Features

- **Explorer** — Browse all 115 LDP tables, columns, FK relationships, and visual join graph
- **Query Builder** — Select tables/columns, add WHERE filters, auto-join via FK path-finder
- **Ask AI** — Describe a report in plain English, get SQL generated by Gemini
- **Saved Queries** — Save and re-run queries

## API Endpoints

| Method | Path                    | Description                       |
| ------ | ----------------------- | --------------------------------- |
| GET    | `/api/schema`           | All tables/columns                |
| GET    | `/api/schema/{table}`   | Table detail + relationships      |
| GET    | `/api/path?from=X&to=Y` | FK join path between tables       |
| GET    | `/api/derived`          | Derived table catalog             |
| POST   | `/api/build`            | Build SQL from query definition   |
| POST   | `/api/execute`          | Run SQL against Postgres          |
| POST   | `/api/nl`               | Natural language → SQL via Gemini |
| POST   | `/api/saved`            | Save a query                      |
| GET    | `/api/saved`            | List saved queries                |
| GET    | `/api/health`           | Health check                      |
